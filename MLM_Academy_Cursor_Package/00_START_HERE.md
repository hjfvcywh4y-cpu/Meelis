# MLM Academy — пакет постановки задачи для Cursor

Этот пакет нужен, чтобы Cursor собрал **оболочку B2C-платформы MLM Academy**: навигацию, каталог, личный маршрут, результаты, страницы разделов и универсальную оболочку трека.

Внутреннего содержания треков здесь намеренно нет. В каталоге лежат только метаданные 112 будущих треков: стабильный ID, название, ситуация, результат, раздел, формат и связи с продолжением.

## Что передать Cursor

1. Скопировать всю папку `MLM_Academy_Cursor_Package` в корень нового или существующего проекта.
2. Открыть этот проект в Cursor.
3. Запустить Agent/Composer в режиме работы со всем проектом.
4. Вставить сообщение ниже без сокращений.

```text
Прочитай файл MLM_Academy_Cursor_Package/01_MASTER_PROMPT.md и все файлы, на которые он ссылается. Выполни задачу полностью по этапам из мастер-промпта. Не ограничивайся планом и не останавливайся после создания каркаса: собери работающую оболочку, подключи реестр, проверь маршруты, адаптивность, тесты и production build. Внутреннее содержание треков не создавай и не выдумывай. Если в репозитории уже есть код, сначала изучи его и встроись без разрушения существующего проекта. Все существенные решения и найденные ограничения фиксируй в IMPLEMENTATION_LOG.md.
```

## Какие файлы считаются источниками правды

- `01_MASTER_PROMPT.md` — что именно Cursor должен построить.
- `02_PRODUCT_ARCHITECTURE.md` — экраны, роли, состояния, навигация и бизнес-правила.
- `03_DESIGN_SYSTEM.md` — визуальный язык и компоненты.
- `04_ACCEPTANCE_CRITERIA.md` — проверка результата.
- `data/sections.json` — шесть B2C-разделов.
- `data/tracks.catalog.json` — полный каталог 112 треков без внутреннего содержания.
- `data/pilot.graph.json` — первый маршрут из 16 узлов.
- `data/recommendation.rules.json` — правила рекомендаций v0.
- `schemas/*.json` — текущий контракт метаданных и будущий контракт содержания.
- `reference/design-reference.html` — визуальный референс, а не production-код.

## Что не нужно загружать Cursor на этом этапе

- PDF Рыбкина;
- фотографии страниц книги;
- прежний Excel-реестр;
- тексты отдельных треков;
- B2B-исследования международных MLM-компаний.

Всё необходимое для оболочки уже извлечено в JSON. Источник нужен будет позже, когда начнётся производство конкретных треков.

## Каким должен быть результат работы Cursor

Работающее адаптивное приложение, которое:

- строит интерфейс из JSON, а не из захардкоженных карточек;
- знает все 112 Track ID и шесть разделов;
- показывает неопубликованные треки только в режиме разработки/предпросмотра;
- имеет связную навигацию без тупиков;
- содержит универсальную пустую оболочку Track Player;
- готово к последующему подключению Supabase и содержимого треков;
- проходит lint, тесты и production build.
