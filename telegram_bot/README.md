# Simple Telegram bot using python-telegram-bot

This folder contains a minimal Telegram bot implementation and instructions to run it.

Files:
- bot.py — the bot implementation
- requirements.txt — Python dependencies
- .env.example — example environment variables
- .gitignore — ignores .env and virtualenv

Run:
1. Install dependencies: `pip install -r requirements.txt`
2. Set environment variable `TELEGRAM_TOKEN`
3. Run: `python bot.py`
