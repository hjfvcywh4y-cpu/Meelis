# Оболочка MLM Academy на Tilda

Это **основная v1-платформа**. Next.js в соседней папке — прототип, его не деплоим
и не удаляем.

Страницы собираются в папке Tilda «MLM Academy». Оболочка опубликована
по адресу `/academy`. Живую главную сайта `/` не трогаем.

## Что здесь лежит

```
tilda/
  src/mlma.css          стили, только внутри .mlma
  src/domain.js         санитайзер, статусы, рекомендации, маршруты
  src/search.js         локальный retrieval и fallback AI-rerank
  src/ui.js             рендер всех экранов
  generate.mjs          собирает paste-ready T123 и локальный предпросмотр
  serve.mjs             локальный сервер с теми же URL, что на Tilda
  dist/t123/            готовые блоки для вставки
  dist/preview/         полные HTML-страницы для проверки
  dist/TILDA_CHECKLIST.md
```

Старый файл `showcase-block.html` — витрина-заглушка под Next.js. Для платформы
на Tilda он больше не нужен.

## Сборка и проверка

Из каталога `mlm-academy/`:

```bash
pnpm tilda:generate
pnpm tilda:test
pnpm tilda:serve      # http://127.0.0.1:4173/academy
```

Генератор выбрасывает ошибку, если в JSON просочились внутренние поля
(`priority`, `pageStatusRaw`, `Осовременивание`, `mlmacademy.ru/track` и т.п.).

## Как устроена оболочка

Один очищенный каталог + один движок на всех страницах. Содержание треков не
выдумывается: у всех 112 записей `publicationStatus: planned` и
`contentStatus: metadata_only`, поэтому кнопки «Начать трек» нет, прогресс
не рисуется как «0 из N».

| URL | Экран |
|---|---|
| `/academy` | Главная |
| `/start` | Выбор ситуации |
| `/library` | Каталог, поиск, фильтры |
| `/library/a1`…`/library/a6` | Разделы |
| `/track?id=a3-002` | Универсальная оболочка трека |
| `/my`, `/my/route`, `/my/results`, `/profile` | Кабинет |
| `/access` | Модель доступа без оплаты |
| `/preview/catalog` | Все 112 карточек, только редактор |

Пока у трека нет отдельной Tilda-страницы, карточка ведёт на `/track?id=…`.
Когда страница `track/a3-002` появится, ID добавляется в
`config.dedicatedTrackPages` генератора.

Предпросмотр на `*.tilda.ws` и localhost показывает все 112 карточек.
На боевом домене после публикации библиотека покажет только опубликованные
треки — сейчас это ноль, и пустое состояние честное.

Профиль и маршрут хранятся в `localStorage` (`mlma.profile.v1`). Это не замена
Tilda Members: Members закрывает кабинет, а рабочий контекст остаётся в браузере.

## Сборка в Tilda

Пошаговый чеклист — `dist/TILDA_CHECKLIST.md`.

Кратко:

1. Создать страницы в папке «MLM Academy», не публиковать.
2. На каждой: HTML в HEAD из `00-head.html`, скрыть header/footer Tilda.
3. Вставить T123-блоки: CSS → data → domain → ui → mount.
4. Подключить Members (Настройки сайта → Подключаемые модули → Личный кабинет).
   Группы: Guest (пусто), Member, Editor. Оплату не подключать.
5. Member и Editor: `/my`, `/my/route`, `/my/results`, `/profile`.
   Только Editor: `/preview/catalog`. Публичные страницы академии в группы не добавлять.
6. Живую главную `/` и маркетинговые страницы в группы не добавлять.

В редакторе Tilda блок T123 показывает исходный код. Оболочка рисуется после
публикации страницы. Адрес `/academy` не заменяет живую главную `/`.
Оболочка опубликована: https://mlmacademy.ru/academy

## Поиск

Локальный движок в `src/search.js` — быстрый fallback: нормализация, опечатки,
стемминг, синонимы, интенты, веса полей. Если в HEAD страницы задан
`window.MLMA_RERANK_URL`, браузер отправляет запрос и 10–15 кандидатов на
серверный proxy. Ключ модели в Tilda не попадает. Заготовка:

- Next.js: `src/app/api/search/rerank/route.ts`
- Cloudflare Worker: `search-proxy/worker.js`

Без URL или при ошибке/таймауте 2.5 с остаётся локальный рейтинг.
Несовпадения не подменяют «ближайшие» первыми карточками A1.


## Шрифты

Onest и JetBrains Mono подключаются через Google Fonts **в HEAD страницы
академии**, не в настройках всего сайта. Иначе перерисуется текущий сайт на
Tilda Sans.
