# MLM Academy — оболочка платформы

Адаптивная B2C-оболочка библиотеки рабочих треков: навигация по ситуациям,
каталог из 112 треков, личный маршрут, результаты и универсальная страница
Track Player.

Внутреннего содержания треков здесь нет намеренно. Мы собрали станок, а не
продукцию: как только у трека появятся шаги, оболочка начнёт показывать их без
единой правки интерфейса.

## Требования

- Node.js 20+
- pnpm 10+

## Запуск

```bash
pnpm install
pnpm dev            # http://localhost:3000
```

## Проверки

```bash
pnpm lint           # ESLint
pnpm typecheck      # tsc --noEmit
pnpm test           # Vitest, доменная логика и целостность каталога
pnpm build          # production build (standalone)
pnpm start          # запуск собранного приложения

pnpm e2e:install    # один раз: браузер для Playwright
pnpm e2e            # smoke-тесты ключевых маршрутов

pnpm verify         # lint + typecheck + test + build
```

## Переменные окружения

Реальные значения задаются в `.env.local` или в окружении площадки.
Шаблон без значений — в `.env.example`.

| Переменная | Назначение |
|---|---|
| `ENABLE_CATALOG_PREVIEW` | `true` открывает предпросмотр: видны все 112 карточек, включая неопубликованные. В production не задаётся. |
| `ENABLE_ADMIN_CATALOG` | `true` открывает служебный экран `/admin/catalog` в production. По умолчанию он доступен только в dev или вместе с предпросмотром. |
| `NEXT_PUBLIC_SHOWCASE_URL` | Необязательная ссылка на внешнюю витрину (например, страницу на Tilda). |

Оба режимных флага читаются только на сервере. Query-параметром их включить
нельзя.

## Маршруты

| Маршрут | Экран |
|---|---|
| `/` | Главная: шесть входов по ситуациям |
| `/start` | Один вопрос → раздел |
| `/library` | Каталог, поиск и фильтры |
| `/library/[sectionId]` | Раздел A1–A6 |
| `/track/[trackId]` | Универсальная оболочка трека |
| `/my` | Личная главная, один следующий шаг |
| `/my/route` | Текущая ветка маршрута |
| `/my/results` | Произведённые результаты |
| `/profile` | Рабочий профиль |
| `/access` | Модель доступа без оплаты |
| `/admin/catalog` | Проверка реестра, только dev/admin |

Канонический URL — lowercase (`/track/a1-004`). Uppercase-адреса редиректятся.

## Архитектура

```
src/domain/    типы, схемы Zod, санитайзер, маршруты, поиск, статусы,
               рекомендации, валидатор каталога, контракты репозиториев
src/server/    server-only загрузчик реестра и режимные флаги
src/lib/       Local Storage репозитории, аналитика (no-op контракт)
src/components дизайн-система и блоки экранов
src/data/      копии JSON из пакета постановки задачи
```

Полный реестр читается только на сервере (`import 'server-only'`). В UI попадает
`PublicTrackMetadata` — 12 разрешённых полей, собранных белым списком.
Внутренние поля (`priority`, `source`, `adaptationLevel`, `transformationType`,
`internalNote`, `pageStatusRaw`, `legacyPublicUrl`) в клиентский bundle не
попадают; это проверяется тестом.
