# Что отсутствует для утверждённой политики

Страница `/privacy` — технический черновик. Юридический текст нельзя выдумать.

Не хватает:

1. Полное наименование оператора персональных данных
2. ИНН / ОГРН (если применимо)
3. Юридический и почтовый адрес
4. Контакт для запросов субъекта (email/форма)
5. Цели и правовые основания обработки
6. Сроки хранения
7. Перечень обработчиков: Tilda, Cloudflare, будущие Supabase и ЮKassa
8. Трансграничная передача
9. Порядок удаления и выгрузки
10. Дата утверждения и версия документа

Пока этого нет:

- согласие в профиле — только интерфейсная отметка в браузере;
- артефакты не отправляются на сервер;
- поиск предупреждает не указывать чужие ПДн;
- выгрузка с устройства работает локально;
- запрос удаления нельзя направить утверждённому оператору.

Тексты предупреждений, которые уже в интерфейсе:

- поиск: «Не указывайте имена, телефоны и другие персональные данные третьих лиц.»
- результат: «Не добавляйте в результат персональные данные других людей без их согласия.»
