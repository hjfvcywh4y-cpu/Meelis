# A3-016 · Cursor-ready пакет

Полный установочный комплект remediation-трека **A3-016 «Открыть разговор через настоящий повод»** для существующей MLM Academy full graph v3.

## Главное

- A3-016 — не генератор предлогов и не школа small talk.
- Он проверяет, есть ли реальный факт, прозрачная цель, уместный момент и право на контакт.
- При подтверждённом поводе маршрут возвращается в A3-002.
- Если повода нет — WAIT_UNTIL; система не производит сообщение ради активности.
- При запрете или эксплуатации уязвимости — DONE.
- AI необязателен, по умолчанию выключен и работает только как критик риска. Он не подтверждает факты и не маршрутизирует.
- Полные тексты и данные контакта остаются локально.
- Статус после установки — REVIEW. Production deploy, migrations, payment и paid navigation запрещены.
