# Продуктовая спецификация A3-008

## Назначение

A3-008 превращает совершённое действие в наблюдаемый факт и следующий маршрут. Пользователь не проходит ещё один урок. Он отвечает на один вопрос: **«Что произошло?»**

## Шесть исходов

| Исход | Что требуется | Решение Route Engine |
|---|---|---|
| Встреча подтверждена | дата/время и формат | RR2-026 → A3-010 |
| Попросил вернуться позже | явное разрешение и дата | RR2-027 → A5-010 |
| Отказался | факт отказа | RR2-028 → A5-014 |
| Пока не ответил | срок ожидания, число повторов 0–1 | RR2-029 → WAIT_UNTIL |
| Дал рекомендацию с разрешением | подтверждённое разрешение | RR2-030 → A3-003 |
| Следующего действия нет | структурированный stop code | RR2-031 → DONE |

## Пользовательский поток

1. Исходный трек совершает полевое действие и по своему RouteRule открывает панель A3-008.
2. Пользователь выбирает один из шести фактических исходов.
3. Форма показывает только обязательные для этого исхода структурированные поля.
4. Личные заметки, адрес встречи и данные человека остаются локально.
5. Сервер проверяет identity, entitlement, product grant и владение исходным instance.
6. Outcome event и RouteDecision записываются атомарно.
7. Пока paid navigation выключена, следующий трек показывается заблокированным без URL.

## Непереговорные правила

- Отказ — не «возражение» и не повод для ветки убеждения.
- «Позже» без разрешения и даты не открывает follow-up.
- Молчание означает ожидание, а не согласие.
- Рекомендация без разрешения не открывает A3-003.
- Не более одного корректного повторного контакта в ветке NO_REPLY.
- Никакой автоматической отправки сообщений или звонков.
- A3-008 не использует AI: исход выбирает пользователь, RouteRule детерминирован.

## Источник и современная граница

Рыбкин, разделы 10.3.5–10.3.6, задаёт полезное ядро: после разговора подтвердить договорённость и зафиксировать дату, место, подготовку и впечатления. В продукт переносится ядро фиксации и следующего шага. Манипулятивная формулировка о «моральном праве диктовать условия» не переносится: она противоречит свободе выбора и правилам MLM Academy.

Точные слова человека и впечатления могут храниться только как локальная заметка пользователя. Сервер получает минимальные сервисные факты.

## Готовность

Definition of Done: одна форма фиксирует исход, необходимые даты/разрешения и следующий шаг; сохраняет outcome и решение идемпотентно; корректно выдаёт TRACK, WAIT_UNTIL или DONE; не создаёт отдельный урок; не передаёт PII.
