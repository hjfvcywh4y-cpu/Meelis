# A3-002 — готовый пакет для Cursor

Версия содержания: `0.1.0`  
Версия передаваемого архива: `1.1`  
Статус: `REVIEW`  
Назначение: первый эталонный пакет для установки в маршрутную архитектуру MLM Academy.

## Что находится в комплекте

1. `01_PRODUCT_SPEC.md` - полная продуктовая и методическая спецификация.
2. `package.json` - машинный пакет по `track-package.schema.json`.
3. `content/content.json` - server-only структура платного трека.
4. `public/public-meta.json` - безопасная публичная карточка.
5. `demo/demo-sandbox.json` - обезличенное демо без live instance.
6. `ai/entry-dataset.json` - запросы для AI-назначения трека и отрицательные примеры.
7. `ai/message-assistant-contract.json` - контракт помощника внутри трека.
8. `analytics/analytics-contract.json` - события и разрешённые свойства.
9. `tests/acceptance-cases.json` - продуктовые, маршрутные, access и privacy тесты.
10. `graph/a3-002-connection-index-v3.json` — контрольный снимок узла A3-002 из полного графа v3.
11. `02_ARCHITECTURE_BINDING.md` — человеческое объяснение входов, выходов, циклов и закрытых слотов.
12. `CURSOR_INSTALL_PROMPT.md` - единственный промпт для установки после аудита архитектуры.

## Что передать Cursor

Передайте Cursor **весь ZIP без выборочного копирования файлов** и одно сообщение:

> Распакуй архив. Это готовый пакет трека A3-002 для существующего проекта MLM Academy. Полностью прочитай `00_START_HERE.md`, затем выполни `CURSOR_INSTALL_PROMPT.md`. Не создавай новый проект, не включай оплату, не деплой production.

Все продуктовые решения, Track ID, связи, outcomes и ограничения уже находятся внутри. Cursor не должен придумывать соседей или менять граф.

## Решение по выпуску

Этот пакет готов для локальной установки и продуктового review. Он не должен автоматически публиковаться, деплоиться или открываться пользователю.

До пилота существующие RR2-014/RR2-015/RR2-016 и новый безопасный терминал RR3-A3-002-STOP остаются `PILOT_DRAFT_TO_TEST`.

## Контрольная логика

```text
Есть настоящий повод + уместен канал
  -> собрать короткое сообщение
  -> проверить прозрачность и отсутствие давления
  -> отправить
  -> MESSAGE_SENT
  -> A3-008

Нет настоящего повода
  -> MESSAGE_NOT_SENT_NO_REASON
  -> A3-016

Есть конкретный барьер действия
  -> MESSAGE_NOT_SENT_ANXIETY
  -> A3-014

Есть явная граница / запрет / неуместность
  -> MESSAGE_STOPPED
  -> DONE
```

Текст сообщения, имя, телефон, email, ник, фактический повод и ответ контакта остаются только на клиенте.
